# Original character art

**Restored in version 3:** the original illustrations are used again in the first arena, event cards and launch previews. No new character images were generated for this restoration. The version 2 SVG characters remain on branch `archive/v2-lab` and tag `v0.2.0-lab`.

Generated using the built-in `image_gen` tool through the `imagegen` skill; no API-key or CLI fallback was used. The images are original to this project, with no reference artwork copied from the research sites. Generated alpha was retained. Sharp was used only for lossily encoding resized delivery copies as WebP.

## Final prompt: Zombie Neuro Fly

Use case: stylized-concept. Asset type: transparent character sprite for an original cartoon arcade battle website. Primary request: Zombie Neuro Fly, an absurdly muscular mutant housefly with an oversized exposed pink cartoon brain, enormous bloodshot red compound eyes, a manic toothy grin, lime green and dark olive body, insect wings with pale ivory veins, ragged lab straps and chunky biotech tubes, two oversized clenched fists. Looks chaotic, funny and weirdly lovable. Hand-inked underground comic / 1990s gross-out cartoon illustration, thick dark irregular ink outlines, detailed cel shading, sharp silhouette, small halftone patches, professional original game character concept. Full body three-quarter view facing RIGHT ready to fight. Floating dynamic pose, wings spread, no floor. Center character in frame with padding so no body part clipped. Radioactive lime green, toxic yellow, pink brain, ink black. Transparent background, isolated character, no text, no letters, no watermark. No gore, no scene, no background effects. Portrait asset.

## Final prompt: GPT-6 Astra

Use case: stylized-concept. Asset type: transparent character sprite for an original cartoon arcade battle website. Primary request: GPT-6 Astra, a hilariously overpowered smug AI robot deity. Large ivory and electric periwinkle helmet with a black face visor and two expressive cyan eyes plus smug pixel mouth, bright cyan compute core in chest, floating oversized rounded mechanical fists, armored chunky blue and ivory body, a thin tilted golden halo above the helmet and small orbiting computer modules. Cute villain energy. Hand-inked underground comic / 1990s cartoon illustration, thick dark irregular ink outlines, detailed cel shading, sharp silhouette, small halftone patches, professional original game character concept. Full body three-quarter view facing LEFT ready to fight. Floating dynamic pose, no floor. Center character in frame with padding so no body part clipped. Electric blue, cyan, periwinkle, ivory, ink black with yellow halo. Transparent background, isolated character, no text, no letters, no watermark. No scene, no background effects. Portrait asset.
